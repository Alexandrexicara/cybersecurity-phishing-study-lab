AMBIENTE WINDOWS

Como usar no Windows

O painel continua sendo acessado pelo navegador do Windows. Para ferramentas de linha de comando compatíveis com Linux, o Windows pode usar WSL2 sem substituir o Windows nem instalar outro sistema como principal.

1. Verifique o WSL

Abra o PowerShell como administrador e execute wsl --status.

2. Instale o ambiente, se necessário

Execute wsl --install -d Ubuntu e reinicie o computador se o Windows solicitar.

3. Abra o Ubuntu

Conclua a criação do usuário Linux dentro do terminal Ubuntu. Isso é apenas um ambiente de compatibilidade dentro do Windows.

O WSL2 não é necessário para usar as ferramentas que rodam diretamente no painel web. Ele é uma opção para utilitários locais compatíveis. O painel atual ainda não possui uma ponte local para executar comandos do computador.
